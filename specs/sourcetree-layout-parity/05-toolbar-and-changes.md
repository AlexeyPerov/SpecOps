# GL-05 — Общий toolbar и режим Changes

**Статус:** Planned. **Зависимости:** GL-01, GL-02, GL-04.

## Работы

- [ ] Вынести в toolbar подписанные действия Commit, Pull, Push, Fetch, Branch, Merge, Stash; справа — открыть remote, показать папку, терминал, настройки, где доступны платформенные команды.
- [ ] Fetch сделать явным действием. Pull/Push открывают окна GL-06/07 вместо немедленного запуска команды.
- [ ] Commit открывает Changes и фокусирует сообщение; Branch и Stash используют текущие сценарии. Merge недоступен с объяснением до реализации соответствующей Git-операции.
- [ ] В Changes слева staged/unstaged файлы и форма коммита, справа diff выбранного файла. Сохранить stage selected/all, unstage selected и commit; не обещать staging строк/блоков.
- [ ] Учитывать busy/cancel/error, ahead/behind и наличие remote; счётчики показывать только из актуального состояния. Не копировать значения бейджей со снимка.
- [ ] Узкое окно сворачивает второстепенные действия в overflow, сохраняя доступность и подписи для accessibility.
- [ ] Сохранить очередь, pre-git save guard, существующие проверки bare/detached/no-upstream, обновление файлов/refs после операции и запрос авторизации.

## Приёмка

- [ ] Переключение History ↔ Changes сохраняет сообщение коммита и корректный выбор, не отправляет команды автоматически.
- [ ] Недоступные действия объяснимы; видимая кнопка не создаёт впечатление реализованной операции при отсутствии backend.
- [ ] Уже выполняющаяся мутация исключает конфликтующий запуск из toolbar, дерева, диалога или другого окна в рамках текущих гарантий очереди.
- [ ] Cancel останавливает операцию, повторный клик не создаёт дубликаты; результат согласован с реальным Git-состоянием.

**Проверка:** mounted toolbar/navigation tests, регрессия текущего stage/commit и remote busy/cancel flow.
