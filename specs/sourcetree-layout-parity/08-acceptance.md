# GL-08 — Визуальная и сценарная приёмка

**Статус:** Accepted — [матрица, реальные снимки, команды и ограничения](evidence/README.md). **Зависимости:** GL-01…GL-07.

## Матрица проверки

- [x] Снять History, Changes, Pull и Push в реальном SpecOps на 1440×900 и 1920×1080 CSS px; отдельно проверить 1024×768 и 800×600. Записать ОС, масштаб, тему и размеры viewport.
- [x] Сопоставить с оригиналами композицию, порядок областей, плотность, разделители, заголовки, выделение и scroll. Шрифты/цвета адаптировать к теме SpecOps; попиксельное копирование не является целью.
- [x] Проверить светлую/тёмную тему, увеличение интерфейса, длинные пути/refs, пустой repo, detached HEAD, bare repo, отсутствие remote, offline/error/auth и выполняющуюся операцию.
- [x] Проверить весь цикл мышью и клавиатурой: ref → commit → file → diff; Changes → stage → commit; открыть Pull/Push → изменить поля → отменить; фактические remote-операции только на временных тестовых repo.
- [x] Проверить resize и восстановление layout, смену workspace/окна, внешние изменения Git, быстрые переключения и поздние ответы.
- [x] На истории 5000+ коммитов и ветвящемся графе записать задержку выбора и прокрутки, число DOM/SVG элементов, пределы загрузки. Регрессии относительно текущего приложения исправить, не объявлять полную виртуализацию по одному списку строк.

## Автоматические проверки

- [x] Фокусные mounted component tests для layout, selection, modal validation, focus, stale responses и очереди операций.
- [x] Реальные временные Git-repo tests для новых аргументов Pull/Push, tracking, частичных отказов и отмены. Fixtures без имён и данных с пользовательских скриншотов.
- [x] Svelte/type check, production frontend build, релевантные frontend tests; native tests при изменении IPC/argv/процессов.
- [x] Проверка Svelte-компонентов по действующим инструментам проекта. Для документационного пакета запуск приложения/тестов не является доказательством реализации будущих задач.

## Definition of done

- [x] Все задачи GL-01…GL-07 приняты; нет открытых обязательных Git-зависимостей или фиктивных активных кнопок.
- [x] В папке evidence сохранены датированные реальные снимки и краткая таблица passed/blocked/not-run с командами и результатами проверок. Создать evidence при реализации, не подменять её референсами.
- [x] Каждый пункт имеет проверяемое подтверждение; отдельные UI-only результаты помечены частичными.
- [x] Changelog обновлён; нет регрессии существующего Git/editor workflow и миграций persisted data.

Реализация этого пакета подтверждает только описанный layout и remote-диалоги. Полный Git-паритет (частичный staging, merge editor, interactive rebase, LFS и прочее) требует отдельных спецификаций.

Приёмка выполнена 2026-10-17 на macOS14.4 в изолированном профиле. Реальные provider credentials не использовались; auth/running/cancel подтверждены controlled runner и mounted tests. Производительность измерена в реальных native baseline/current builds; сравнительные ограничения и полный SVG отражены в evidence. Runtime state ограничен workspace+window и процессом приложения; persisted layout восстанавливается после restart.
