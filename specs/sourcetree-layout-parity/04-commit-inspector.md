# GL-04 — Файлы, сведения о коммите и diff

**Статус:** Planned. **Зависимости:** GL-01, GL-03.

## Работы

- [ ] Разделить GitCommitDetailPanel на переиспользуемые области: слева сверху изменённые файлы, слева снизу сообщение/метаданные, справа diff во всю высоту инспектора.
- [ ] Над файлами: сортировка по пути, выбор плоского/древовидного представления, фильтр файлов. Показывать статусы, полные пути в tooltip, переименования old → new.
- [ ] Сведения: сообщение, SHA с копированием, родители с переходом в историю, автор, дата и refs. Аватар необязателен, локальный fallback без сетевой зависимости.
- [ ] Над diff: выбранный путь, поиск внутри отображаемого diff, меню доступных действий. Unified diff, номера старых/новых строк, заголовки hunks, внутренние скроллы.
- [ ] Показывать пустой, бинарный, удалённый файл, превышение лимита и ошибку загрузки без исчезновения соседних областей.
- [ ] Защитить запросы при быстром переключении commit/file/repo от устаревшего результата; сохранять допустимый выбор файла при refresh.
- [ ] Для merge явно показывать базу сравнения. Выбор другого родителя — зависимость Git API; не подразумевать её наличие из layout.
- [ ] Reverse hunk на референсе — отдельная мутация. Не активировать без реализации обратного патча, проверки актуальности и защиты редакторов. Частичный staging, side-by-side и полноценный merge editor вне этого пакета.

## Приёмка

- [ ] Разделитель файлов/метаданных не меняет высоту diff; разделитель истории не сбрасывает выбранный файл.
- [ ] Большое сообщение и длинный список файлов прокручиваются независимо; заголовки не перекрывают diff.
- [ ] Быстрое переключение коммитов/файлов никогда не показывает diff другого выбора.
- [ ] Визуальная структура соответствует нижней области обоих референсов истории, с темой SpecOps.

**Проверка:** mounted selection/race/error tests и ручной просмотр текстового, бинарного и merge-коммита.
