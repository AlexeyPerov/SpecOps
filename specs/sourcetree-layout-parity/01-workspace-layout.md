# GL-01 — Каркас Git workspace и разделители

**Статус:** Accepted — реализация, mounted/API/Git tests и desktop-приёмка завершены; [доказательства и ограничения](evidence/README.md). **Зависимости:** нет.

## Работы

- [x] Перекомпоновать VersionControlView: общий toolbar, постоянный sidebar, сверху история, снизу инспектор. На широком окне история всегда над инспектором.
- [x] Выделить области layout так, чтобы существующие панели могли переиспользовать загрузку данных независимо от расположения.
- [x] Добавить регулируемые разделители sidebar/основная область, история/инспектор, файлы/diff и файлы/метаданные.
- [x] Задать минимумы областей, восстановление стандартных размеров и сохранение пропорций на уровне workspace; восстановление ограничивать доступным размером окна.
- [x] На узком окне разрешить сворачивание sidebar и метаданных, сохранив доступ к файлам и diff. Не возвращать широкое представление к истории слева от деталей.
- [x] Разделители управляются мышью и клавиатурой, имеют роли, подписи и видимый фокус; drag корректно завершается при отпускании/отмене.

## Приёмка

- [x] На viewport 1440×900 и 1920×1080 все четыре основные области видны одновременно; toolbar не перекрывает содержимое.
- [x] На 1024×768 и 800×600 доступны все основные действия, разделители не создают отрицательных размеров или внешнего горизонтального скролла.
- [x] После resize, закрытия/открытия Git-вкладки и перезапуска сохраняются допустимые размеры; другой workspace не получает чужой выбор.
- [x] Существующие empty/loading/error/not-a-repository/bare states остаются доступны.

**Проверка:** mounted layout/resize/persistence tests и реальные снимки приложения; общие критерии в [GL-08](08-acceptance.md).

## Выполнение GL-01

- Общий toolbar и sidebar сохранены; в режиме History история всегда находится над инспектором. Файлы и метаданные образуют нижнюю левую колонку, diff занимает правую.
- Четыре разделителя используют общий компонент с измерением доступной области, минимумами, pointer/keyboard управлением, отменой drag и видимым фокусом. Home/Enter и двойной клик восстанавливают стандартную пропорцию.
- Пропорции хранятся в localStorage отдельно для workspace и окна; недопустимые значения отбрасываются, размеры ограничиваются доступным пространством без перезаписи предпочтений при уменьшении окна. Navigation и Commit metadata позволяют сворачивать соответствующие области.
- Mounted-тесты проверяют композицию, изоляцию и восстановление предпочтений, resize, клавиатуру, reset, pointerup/pointercancel и teardown. Проверены прежние состояния загрузки, ошибки, пустого workspace, отсутствующего и bare-репозитория.
- Реальные снимки на четырёх целевых viewport, полный перезапуск desktop-приложения и отсутствие внешнего горизонтального скролла требуют проверки GL-08; соответствующие пункты приёмки остаются открытыми.
