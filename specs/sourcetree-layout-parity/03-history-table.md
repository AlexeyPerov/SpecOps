# GL-03 — Компактная таблица истории

**Статус:** Planned. **Зависимости:** GL-01, GL-02.

## Работы

- [ ] Превратить список в таблицу Graph / Description / Commit / Author / Date с общей вертикальной прокруткой, закреплёнными заголовками и регулируемыми колонками.
- [ ] Разместить ref badges перед сообщением; выделять всю выбранную строку. Сохранить единое выравнивание графа и строк при скролле, пагинации и смене плотности.
- [ ] Над таблицей разместить scope веток, remote refs, порядок истории, compact mode и Jump to. Существующие scope переиспользовать; дополнительные сортировки и ref queries требуют явной поддержки backend.
- [ ] Добавить строку Uncommitted changes с переходом в Changes; не выдавать её за настоящий коммит или SHA.
- [ ] Навигация стрелками, Home/End, выбор коммита, копирование SHA и переход по ref/родителю согласованы с инспектором.
- [ ] Поиск/Jump to SHA или ref ищет в репозитории, а не только в уже загруженных строках. При отсутствии API — отдельная зависимость; нельзя сообщать «не найдено» только из-за лимита страницы.
- [ ] Сохранять выбор и scroll при refresh; поздние ответы старого repo/ref игнорировать. Отсутствующий после фильтра коммит не оставляет чужой diff.
- [ ] Проверить лимит 5000 коммитов и полный SVG графа: явно показывать предел загрузки либо реализовать продолжение; виртуализация строк не считается виртуализацией графа.

## Приёмка

- [ ] Граф разветвлённой истории, merge, несколько badges, длинные сообщения и detached HEAD отображаются без рассинхронизации.
- [ ] Выбор коммита обновляет нижнюю область без изменения высоты истории и без скачка прокрутки.
- [ ] Author/Date/SHA остаются читаемыми; на узком окне допускается горизонтальная прокрутка самой таблицы.
- [ ] Compact mode и разные масштабы не нарушают совмещение узлов и строк.

**Проверка:** graph/table selection tests, реальная история с merge и пагинацией; [GL-08](08-acceptance.md).
