**Recorded:** 2026-10-04 21:34 Europe/Volgograd. **State:** developer source lifecycle implemented; native interactions, paid inference, installed and release acceptance remain open.

## Pinned native contract and creation semantics

This phase uses the installed official `@anthropic-ai/claude-agent-sdk` **0.3.289** root SDK and bundled native **2.1.289**. Checked native `Options`, `Query`, `SDKMessage`, `SDKUserMessage`, `SessionMessage`, `SpawnOptions` and `SpawnedProcess` declarations. Official root-package session readers expose `getSessionInfo` and `getSessionMessages`; their process-level configuration lookup requires a separate private-environment reader process for each profile. The host never switches `process.env` between accounts.

Native query initialization accepts an explicit session UUID, actual canonical workspace cwd, explicit catalog model, empty setting sources, empty tools, manual permission mode and a deny callback. Initialization uses an idle input iterable and `supportedModels`; no inference prompt or real credential is required for the source probe. **Control-only initialization does not create a conversation transcript.** Its reference is an explicitly reserved UUID with persisted `started:false`, and an empty authoritative history is allowed only in that state. The first prompt uses the same native `sessionId`; accepted-dispatch intent is written before invoking the SDK. Later sends use native `resume`. A missing transcript after dispatch intent fails explicitly and preserves the local session/binding; it never creates another native session or replays an earlier prompt. Cancellation during unresolved initialization conservatively retains dispatch intent rather than risking a silent second first prompt.

Bindings persist the profile, native session UUID, canonical cwd, model and settings, stable native user UUID to client message ID mapping, host cursor and native cumulative cost baseline in private atomic files. A private credential digest prevents continuation under a replacement profile credential. Frontend references contain only non-secret native binding settings. Fresh adapter and fresh app state reconstruct the same reference through the production writer; changed workspace/profile/model/settings fail before dispatch. No migrations or compatibility paths were added.

## Streams, cancellation and history

Query messages normalize initialization, text and thinking, native tool use/results/progress, per-turn main-loop usage, estimated cost, errors and bounded redacted unknown diagnostics. Native IDs, turn/profile/generation and persisted host sequence correlate every event. Streamed text is reconciled with full assistant messages without duplicate deltas. Lexical carries and an additional private-key suffix retain fragmented secrets before any serialization; queue/state/event depth and native history/normalized hydration have explicit limits. Capacity failure, cancellation, deadline and native iterator failure settle exactly once and drain the terminal stream. A session stays reserved until SDK dispatch and bounded native cleanup settle. Concurrent sends, cancellation during pending auth, stale profile generations and late query initialization have fixtures.

The SDK result declaration explicitly documents `total_cost_usd` as cumulative for a resumed native session when transcript totals exist. The adapter stores the previous native total and emits the nonnegative increment; the repeated-turn fixture checks **0.125 → 0.250 gives 0.125** on the second turn. The shared `usage.recorded` payload maps the SDK's documented per-turn main-loop `usage`; all-agent/model accounting is not advertised in this slice.

Native history is authoritative for user/assistant content and native UUIDs. Tool-result user frames are distinguished from actual user prompts, preventing duplicate client messages. Native thinking/tool/result blocks hydrate neutral events. Final native `message.stop_reason` establishes completed assistant history; absence keeps interruption explicit. Session readers do not return result-only cost/error frames, so history does not invent those values or infer completion from cached UI text. Rich ecosystem/subagent/lifecycle extensions remain C's work.

Native query children remain in the outer host supervisor group. The owner tracks bounded descendants with PID birth stamps, rejects spawn after cancellation, suppresses native stderr at the public boundary and reaps observed descendants even after native-parent exit. Native history readers have bounded output/time and are abortable on profile/host retirement. Immediate unobserved descendant exit, signed installed shutdown and other-platform process behavior remain release gates.
