# GL-03 — Компактная таблица истории

**Статус:** Accepted — реализация, mounted/API/Git tests и desktop-приёмка завершены; [доказательства и ограничения](evidence/README.md). **Зависимости:** GL-01, GL-02.

## Работы

- [x] Превратить список в таблицу Graph / Description / Commit / Author / Date с общей вертикальной прокруткой, закреплёнными заголовками и регулируемыми колонками.
- [x] Разместить ref badges перед сообщением; выделять всю выбранную строку. Сохранить единое выравнивание графа и строк при скролле, пагинации и смене плотности.
- [x] Над таблицей разместить scope веток, remote refs, порядок истории, compact mode и Jump to. Существующие scope переиспользовать; дополнительные сортировки и ref queries требуют явной поддержки backend.
- [x] Добавить строку Uncommitted changes с переходом в Changes; не выдавать её за настоящий коммит или SHA.
- [x] Навигация стрелками, Home/End, выбор коммита, копирование SHA и переход по ref/родителю согласованы с инспектором.
- [x] Поиск/Jump to SHA или ref ищет в репозитории, а не только в уже загруженных строках. При отсутствии API — отдельная зависимость; нельзя сообщать «не найдено» только из-за лимита страницы.
- [x] Сохранять выбор и scroll при refresh; поздние ответы старого repo/ref игнорировать. Отсутствующий после фильтра коммит не оставляет чужой diff.
- [x] Проверить лимит 5000 коммитов и полный SVG графа: явно показывать предел загрузки либо реализовать продолжение; виртуализация строк не считается виртуализацией графа.

## Приёмка

- [x] Граф разветвлённой истории, merge, несколько badges, длинные сообщения и detached HEAD отображаются без рассинхронизации.
- [x] Выбор коммита обновляет нижнюю область без изменения высоты истории и без скачка прокрутки.
- [x] Author/Date/SHA остаются читаемыми; на узком окне допускается горизонтальная прокрутка самой таблицы.
- [x] Compact mode и разные масштабы не нарушают совмещение узлов и строк.

**Проверка:** graph/table selection tests, реальная история с merge и пагинацией; [GL-08](08-acceptance.md).

**Проверено автоматически (2026-10-17):** mounted selection/keyboard/column resize, repository-wide Jump и переход к внешнему ref после Jump, stale repository/ref responses, refresh selection/scroll/depth, пагинация до 5000, compact SVG merge geometry; Git service/API tests и Svelte/type check. Полный SVG ограничен 5000 коммитами, виртуализируются только строки; предел явно показан. Реальная визуальная приёмка длинных сообщений, detached HEAD и масштабов ожидает GL-08.
