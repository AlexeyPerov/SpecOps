# План: группы вкладок, Tasks и Notes как сущности левой панели

Обновлено: 2026-10-22. Статус: фаза 1 завершена; следующая — фаза 2.

Цель — сделать группы вкладок, Tasks и Notes самостоятельными сущностями левой панели наряду с workspace: их можно создавать и удалять так же, как workspace.

## Исходное состояние

- Каждое окно содержит один контекст Notepad (`notepad` в `WindowContextState` и `WindowSessionSnapshot`). Он служит запасным контекстом окна: туда открываются файлы вне workspace, на него переключается окно после закрытия активного workspace.
- Tasks и Notes без workspace — по одному документу на приложение: `global-documents/tasks.json` и `global-documents/notes.md` в каталоге данных приложения. Кнопки в панели переключают окно на Notepad и открывают в нём view-вкладку `workspace-tasks`/`workspace-notes` с `root = null`. Вкладка не хранит идентификатор документа, поэтому два разных документа одного вида открыть нельзя.
- Документы workspace (`.specops/` или каталог данных приложения по корню проекта) этим планом не меняются.

## Целевая модель

### Группы вкладок (своё у каждого окна)

- Окно содержит упорядоченный список групп вкладок. Первая — дефолтная группа: она есть в каждом окне с первого запуска, её нельзя удалить. Остальные группы окно создаёт и удаляет само.
- Группа вкладок — контекст окна, как workspace: у неё свой layout редактора, вкладки и документы. Идентификаторы: `tabs-default` для дефолтной группы и `tabs-<n>` для остальных.
- Дефолтная группа заменяет Notepad во всех ролях запасного контекста окна.
- Список групп хранится в снимке сессии окна. Закрытие окна удаляет его группы, как сейчас удаляет Notepad. Миграции снимков с полем `notepad` нет: такой снимок не восстанавливается.
- Удаление группы с несохранёнными буферами проходит существующий Save/Discard/Cancel. Если удаляется активная группа, окно переключается на дефолтную.
- Файл, открытый вне workspace, попадает в активную группу вкладок, если активна группа, иначе в последнюю использованную группу окна, иначе в дефолтную.
- Вкладку можно перетащить на строку группы в панели.

### Tasks и Notes (общие на приложение)

- Каталог приложения хранит список документов `{ id, kind: tasks | notes, name, order }`. Изменения проходят транзакциями каталога и синхронизируются между окнами.
- Файлы документа: `global-documents/<id>/tasks.json` или `global-documents/<id>/notes.md`. Идентификатор проверяется строго, чтобы путь не выходил за пределы каталога.
- Дефолтных Tasks и Notes нет. Удаление документа после подтверждения удаляет его файл.
- Прежние `global-documents/tasks.json` и `notes.md` не читаются и не переносятся.
- Клик по документу в панели открывает view-вкладку с его идентификатором в активной группе вкладок. Если активен workspace — в последней использованной группе окна, иначе в дефолтной. Повторное открытие фокусирует существующую вкладку. Вкладка показывает имя документа.

### Панель

- Над workspace — секция «Tab groups»: строки с именем, счётчиком вкладок и последними вкладками (развёрнутый режим) или иконкой с инициалом (узкий режим). Кнопка «+» создаёт группу; меню строки — Rename и Delete, у дефолтной группы Delete недоступен.
- Секции «Tasks» и «Notes»: строки документов, кнопка «+», меню Rename, Delete, Move up/down.
- Папки и закрепление для групп и документов в этот план не входят.

## Фазы

1. **Рефакторинг Notepad в группы вкладок.** Поле `notepad` заменяется списком `tabGroups` с дефолтной группой; все обращения к Notepad переходят на помощники групп. Поведение не меняется: в окне одна дефолтная группа. Отдельный коммит.
2. **Создание и удаление групп вкладок.** Действия состояния, защита дефолтной группы, закрытие с несохранёнными буферами, правило открытия файлов, секция панели, перенос вкладок на строку группы.
3. **Хранение Tasks и Notes.** Коллекция документов в каталоге приложения, пути файлов по идентификатору, удаление файла, ключ записи в сервисе документов по идентификатору.
4. **Tasks и Notes в панели и во вкладках.** Секции панели, view-вкладка с идентификатором документа, имя во вкладке, правило выбора группы для открытия.
5. **Спеки и тесты.** Обновить `workspace-tools.md`, тесты групп, документов, защиты дефолтной группы, правила открытия файлов и путей в нативной части.
