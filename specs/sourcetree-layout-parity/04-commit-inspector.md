# GL-04 — Файлы, сведения о коммите и diff

**Статус:** Implemented; mounted/API checks pass, visual acceptance pending GL-08. **Зависимости:** GL-01, GL-03.

## Работы

- [x] Разделить GitCommitDetailPanel на переиспользуемые области: слева сверху изменённые файлы, слева снизу сообщение/метаданные, справа diff во всю высоту инспектора.
- [x] Над файлами: сортировка по пути, выбор плоского/древовидного представления, фильтр файлов. Показывать статусы, полные пути в tooltip, переименования old → new.
- [x] Сведения: сообщение, SHA с копированием, родители с переходом в историю, автор, дата и refs. Аватар необязателен, локальный fallback без сетевой зависимости.
- [x] Над diff: выбранный путь, поиск внутри отображаемого diff, меню доступных действий. Unified diff, номера старых/новых строк, заголовки hunks, внутренние скроллы.
- [x] Показывать пустой, бинарный, удалённый файл, превышение лимита и ошибку загрузки без исчезновения соседних областей.
- [x] Защитить запросы при быстром переключении commit/file/repo от устаревшего результата; сохранять допустимый выбор файла при refresh.
- [x] Для merge явно показывать базу сравнения. Выбор другого родителя — зависимость Git API; не подразумевать её наличие из layout.
- [x] Reverse hunk на референсе — отдельная мутация. Не активировать без реализации обратного патча, проверки актуальности и защиты редакторов. Частичный staging, side-by-side и полноценный merge editor вне этого пакета.

## Приёмка

- [ ] Разделитель файлов/метаданных не меняет высоту diff; разделитель истории не сбрасывает выбранный файл.
- [ ] Большое сообщение и длинный список файлов прокручиваются независимо; заголовки не перекрывают diff.
- [x] Быстрое переключение коммитов/файлов никогда не показывает diff другого выбора.
- [ ] Визуальная структура соответствует нижней области обоих референсов истории, с темой SpecOps.

**Проверка:** mounted selection/race/error tests и ручной просмотр текстового, бинарного и merge-коммита.

## Реализация и проверка

- Файлы и метаданные выделены в отдельные переиспользуемые компоненты; split-композиция остаётся смонтированной при загрузке, отсутствии выбора и ошибках. Фильтр учитывает прежний путь переименованного файла, сортировка и стрелки работают по видимому списку; дерево группирует файлы по каталогам.
- SHA копируется целиком; родитель вызывает существующий repository-wide переход истории, включая ancestry вне загруженной страницы. Refs берутся из выбранной строки истории и обновляются при Refresh той же SHA.
- Поиск по полному загруженному diff показывает количество совпадающих строк, переходит между ними и открывает строки за пределами текущего виртуального окна. Меню содержит только реализованные Copy path / Copy displayed diff.
- Mounted-тесты проверяют выбор и его сохранение/замену при Refresh, независимость разделителей, поздние успешные и ошибочные ответы commit/file/repo, стабильные соседние области, пустой/бинарный/удалённый/слишком большой diff, метаданные и обновление refs. Git API test проверяет оба merge-parent и first-parent список файлов. Svelte/type check: 0 ошибок и 0 предупреждений.
- Ручной desktop-просмотр текстового, бинарного и merge-коммита, независимые скроллы на длинных данных и визуальная геометрия остаются частью GL-08. Выбор другого merge-parent, reverse hunk, частичный staging, side-by-side и merge editor не реализованы и не предлагаются как доступные действия.
