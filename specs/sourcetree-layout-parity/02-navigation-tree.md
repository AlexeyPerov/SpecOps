## Приёмка

- [x] Ветки с общим префиксом, несколько remotes, теги и stash отображаются одновременно и не теряют идентичность при фильтрации.
- [x] Выбор ref не меняет HEAD; checkout выполняется только явным действием.
- [x] Refresh после внешнего изменения refs сохраняет валидный выбор; удалённый выбранный ref даёт понятное состояние.
- [x] Search имеет рабочий сценарий либо явно недоступное состояние до реализации поиска; пустая фиктивная страница не принимается.

**Проверка:** tree/filter/selection tests и визуальная проверка длинного дерева по [референсу](references/history-overview.png).

## Реализация и проверка

- Данные remote tracking refs читаются локально через общий Git runner; открытие дерева не вызывает сеть. `QueryCommitsOptions.revision` задаёт конкретный ref или SHA и сохраняется при pagination.
- Одиночный выбор ветки/тега/stash открывает историю и inspector, не изменяя HEAD. Контекстные Branch/Tag/Stash actions открывают компактную форму существующих операций без дублирующего списка refs; checkout требует отдельного явного нажатия и сохраняет действующие autosave/dirty-tree guards.
- Search показан явно недоступным с объяснением; неподдерживаемые submodules/subtrees скрыты.
- Проверены model/filter/identity/revision tests, mounted keyboard/filter/context/late-response/deleted-ref tests и интеграция sidebar → history → refresh. Svelte/type check: 0 errors, 0 warnings.
- Визуальная проверка большого дерева и desktop-сценариев остаётся в GL-08; галочки выше относятся к реализованному поведению и автоматическим проверкам.
