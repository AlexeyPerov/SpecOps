# GL-02 — Постоянное дерево навигации

**Статус:** Planned. **Зависимости:** GL-01.

## Работы

- [ ] Разместить в sidebar Workspace: Changes, History, Search; ниже Branches, Tags, Remotes, Stashes. Submodules/Subtrees показывать только при доступной реализации либо явно недоступными.
- [ ] Группировать ветки по сегментам имени; remote → группы → ветки. Теги и stash доступны в том же дереве без переключения всей страницы на отдельный список.
- [ ] Отмечать текущую ветку, выбранный элемент, remote HEAD, ahead/behind при наличии достоверных данных; длинные имена сокращать с полным tooltip.
- [ ] Добавить filter внизу sidebar. Совпадения раскрывают родительский путь, очистка восстанавливает пользовательское раскрытие.
- [ ] Разделить выбор для просмотра и checkout: одиночный клик по ref фильтрует/позиционирует историю, явное действие переключает ветку с существующей защитой несохранённых данных.
- [ ] Выбор тега ведёт к его коммиту, stash — к доступным сведениям о stash. Нужные API фильтра по ref/позиционирования/просмотра stash оформить отдельно от визуальной части.
- [ ] Контекстные меню вызывают доступные операции создания/checkout веток, тегов и stash. Новые мутации не возникают только из-за копирования структуры меню.
- [ ] Добавить клавиатурную навигацию дерева, loading/error/empty и изоляцию состояния по repo.

## Приёмка

- [ ] Ветки с общим префиксом, несколько remotes, теги и stash отображаются одновременно и не теряют идентичность при фильтрации.
- [ ] Выбор ref не меняет HEAD; checkout выполняется только явным действием.
- [ ] Refresh после внешнего изменения refs сохраняет валидный выбор; удалённый выбранный ref даёт понятное состояние.
- [ ] Search имеет рабочий сценарий либо явно недоступное состояние до реализации поиска; пустая фиктивная страница не принимается.
